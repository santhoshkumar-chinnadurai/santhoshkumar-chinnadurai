# Modern Interactive Developer Portfolio

A high-performance, interactive personal developer portfolio built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, **Three.js**, and **GSAP**.

---

## 📌 Overview

This repository houses the source code for Santhoshkumar Chinnadurai's interactive portfolio website. It showcases full-stack software projects, verified professional certifications, academic background, and interactive contact channels with smooth 60 FPS visual animations and modern glassmorphism aesthetics.

---

## ✨ Features

- **Interactive 3D Visuals**: Particle aurora backgrounds and custom shaders built with Three.js.
- **Physics-Based UI**: Magnetic buttons and fluid micro-interactions powered by GSAP and Framer Motion.
- **Responsive Modular Sections**:
  - **Hero**: Dynamic rotating role titles and interactive contact triggers.
  - **About & Statistics**: Animated counter statistics and educational background.
  - **Interactive Projects Showcase**: Categorized filterable project grid with tech badges and GitHub/Live links.
  - **Skills Matrix**: Categorized tech stacks with dynamic glow effects.
  - **Certifications Showcase**: Interactive modal views displaying verified certificates (Infosys, Microsoft, Cisco).
  - **Contact Flow**: Integrated contact form with dynamic success feedback via canvas-confetti.
- **Next.js 16 App Router**: Server-side rendering, code splitting, and sub-second page loads.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16.2.7 (App Router)
- **UI Library**: React 19.2.4
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4, PostCSS
- **Animations & 3D**: Three.js, GSAP, Framer Motion
- **Icons & Effects**: Lucide React, Canvas Confetti

## 💻 Installation & Setup

### Prerequisites
- Node.js v18.17+ or higher
- npm / yarn / pnpm

### 1. Clone the repository
```bash
git clone https://github.com/santhoshkumar-chinnadurai/developer-portfolio-nextjs.git
cd developer-portfolio-nextjs
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```

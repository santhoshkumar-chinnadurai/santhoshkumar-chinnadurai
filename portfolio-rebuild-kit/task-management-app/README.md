# Task Management Application

A lightweight, persistent task and workflow management system built with **Node.js**, **Express.js**, and vanilla web standards.

---

## 📌 Overview

The Task Management Application allows users to organize daily workflows by creating, prioritizing, categorizing, and tracking the status of tasks. It features low-overhead file-based JSON persistence (`db.json`) for seamless local operation without database server overhead.

---

## ✨ Features

- **Task CRUD**: Create, read, update, and delete tasks with priority levels (`Low`, `Medium`, `High`, `Urgent`).
- **Status Toggles**: Real-time status switching between `Pending`, `In Progress`, and `Completed`.
- **Persistent Storage**: Automatic state synchronization with a local JSON datastore.
- **RESTful Endpoints**: Clean API routes for querying and modifying task collections.

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Persistence**: JSON-backed local storage
- **Frontend**: HTML5, CSS3, JavaScript

---

## 💻 Installation & Setup

```bash
git clone https://github.com/santhoshkumar-chinnadurai/task-management-app.git
cd task-management-app
npm install
npm start
```
The server starts on port `3000`.
